First release of **Mail-Cal**, a privacy-focused fork of Wino Mail for Windows 10/11 (x64).

## What's new
- **Your calendar in the tray.** Click the Mail-Cal tray icon to see the month and the events of any day, and add an event without opening the app.
- **Private by design.** Mail-Cal only contacts the mail, calendar and contacts accounts you add: no telemetry, no Wino account, no Store purchases, no AI services, no third-party lookups.

## Install
The package is signed with a self-signed Mail-Cal certificate, so Windows needs to trust it once.

1. Download `MailCal_2.3.0.0_x64.msixbundle`, `MailCal.cer` and `Install-MailCal.ps1` into the same folder.
2. Open PowerShell in that folder and run:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-MailCal.ps1
   ```
   Approve the administrator prompt; it adds the certificate to *Trusted People*. Then the script installs Mail-Cal for your user.

Manual alternative: import `MailCal.cer` into **Local Machine > Trusted People** (`certlm.msc`), then double-click the `.msixbundle`.
